lambda function: 
----------------
    ->lambda function is the type of Anonyms function 
    ->lambda function java 8 feature 
    Syntax: 
        (parameters)->expression


    Ex: (a,b)->a+b

    Ex: (a,b)-> {
                int result=a+b;
                return result;
                }
    Ex: (a)->{
            System.out.println(a);
            System.out.println(a+10);
        }

Method reference : 
----------------
    ->Methods reference of the shorthand way of writing a lambda expression when the lambda only calls an existing method 

    ->Method reference [::] is the java 8 feature

    Syntax: 
       i.  className :: staticMethodName  
        
       ii. className ::instanceMethodName

       iii. object :: instanceMethodName

Mysql Statements /Mysql Commands : 
-----------------------------------

    1. DDL [data definition language] -> it focus on structure/scheme of table
        i.   create 
        ii.  drop 
        iii. truncate
        iv.  rename
        v.   alter 


    2. DML [data manipulation language] ->it focus of data modification
        i.   insert 
        ii.  update 
        iii. delete

    3. DQL [data query language] ->it focus on retrieve data from table 
        i. select 
            (where , group by, having, order by, limit)

    4. TCL [Transaction control language] 
        i.  commit
        ii. rollback

    5. DCL[data control  language ]
        i.  grant 
        ii. revoke

Constraints : 
-------------
    ->Constraints are nothing but rules given to the table 

    Single row Constraints : 
        1. unique 
        2. default 
        3. not null 
        4. check
        5. auto_increment

    Multi row Constraints/keys: 
        1. primary key 
            ->combination of unique and not null 
            ->primary key is the Identity of the table (Identity key)
            ->In Table Any one column having primary key but not more than one 


        2. foreign key 
            ->foreign keys allows the null value and duplicate records  
            ->foreign key is the reference of the another table (reference key)
            ->we can write one or more foreign key's in table  


Note: while creating a table column name and datatype is mandatory , but Constraints are optional

JDBC:

JDBC steps : 
-----------

    1. load and register the "driver class" using Class.forName("")
    2. establish the Connection using DriverManager.getConnection(url , username , password) 
    3. prepare statements/createStatement
    4. executeUpdate/execute / resultSet 
    5. close the connection
